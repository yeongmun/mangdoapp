# 오프라인 모드 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 도면을 SVF로 변환해 기기에 미리 내려받고, 인터넷 없이 열어 손상·사진을 입력하며, 연결되면 자동으로 서버에 올린다.

**Architecture:** 서버는 SVF 파생 파일과 뷰어 꾸러미를 캐시해 앱에 준다. 앱은 `Paths.document/offline/`에 꾸러미·도면 파일·손상 기록을 두고, 내려받은 도면은 항상 `file://` 뷰어 페이지로 연다. 뷰어는 `offline=1`일 때 API 대신 앱이 주입한 데이터와 postMessage 다리를 쓴다. 동기화는 목록 화면에서 60초마다·진입 시·뷰어 복귀 시 자동.

**Tech Stack:** Node 24 · TypeScript(NodeNext, `.js` 접미사) · Express 5 · vitest+supertest / 뷰어·PC 페이지 plain ESM JS / Expo SDK 57 · react-native-webview 13.16 · expo-file-system(`File`, `Directory`, `Paths`, `File.downloadFileAsync`).

**Spec:** `docs/superpowers/specs/2026-09-23-offline-design.md` (binding)
