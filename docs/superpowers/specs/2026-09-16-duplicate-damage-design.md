# 손상 복제(같은 손상 여러 개 = nEA)와 첫 그리기 속성창 자동 열기

- 날짜: 2026-09-16
- 앞선 설계: `2026-09-13-damage-attributes-design.md`(속성·개소·라벨), `2026-09-12-damage-types-design.md` §4(선택·이동), `2026-09-16-label-layout-design.md`(라벨·겹침), `2026-09-16-frame-numbering-design.md`(틀 배정), `2026-09-15`/`2026-09-16-sheet-overflow`(산출)
- 상태: 설계 승인됨 (구현 계획 작성 전). 사용자 확인 2026-09-16.

## 1. 바꾸는 이유

사용자 요구(2026-09-16):

1. 손상 유형을 **셀렉트박스에서 고른 뒤 처음 그릴 때만** 속성창이 자동으로 뜨면 좋겠다. 지금은 "속성" 버튼을 눌러야만 열린다.
2. 사내 표기는 **같은 크기의 손상이 2개 이상이면 2EA, 3EA**로 적고 도형은 개수만큼 그린다. 예: 균열 0.2/0.3 3EA = 손가락으로 그린 도형 3개 + 속성 1개. 그려 둔 손상을 **복제**해 개수만큼 늘릴 수 있어야 한다.

사용자 결정:

- 번호 라벨은 **첫 도형에만** 붙인다. 복제본은 도형만.
- 개소는 **도형 수로 자동**으로 맞추되, 속성창에서 직접 고칠 수도 있다.
- 복제본 하나를 선택해 "선택 삭제"를 누르면 **그 도형 하나만** 지운다.
- 사진번호는 지금처럼 쉼표로 한 손상에 여러 장.

## 2. 데이터 — schemaVersion 5

손상 하나가 도형을 여러 개 가진다. 첫 도형은 지금처럼 `geometry`, 나머지는 `copies`다.

```
damage = {
  id, type, createdAt,
  geometry: { kind: 'polyline' | 'rect', world: Point[], dwg: Point[] | null },   // 첫 도형(그대로)
  copies:   Array<{ world: Point[], dwg: Point[] | null }>,                        // 복제본. kind는 geometry와 같다
  measured: { width, length, count },  // count: 도형 수로 자동, 사용자가 고치면 그 값
  attrs: { note, statusText, photoNumbers },
  computed: {...}                      // 첫 도형 기준(변함없음)
}
```

- 검증(`damageDoc.js`): `copies`는 배열이고 각 항목의 `world`는 `geometry.kind`의 점 개수 규칙(사각형 4점, 선 2점 이상)을 따르며 `dwg`는 `null`이거나 `world`와 점 개수가 같다. `geometry`의 규칙과 같다.
- 이행 v4 → v5: 모든 손상에 `copies: []`. 다른 값은 그대로. `SCHEMA_VERSION = 5`. 서버는 이 파일을 그대로 쓰므로 **서버를 다시 시작해야** 한다(안 하면 `schemaVersion은 4여야 합니다`로 저장이 막힌다 — 이전에 겪은 문제).
- 도형 수 `shapeCountOf(damage) = 1 + copies.length`.

### 개소 자동 규칙

- 복제하거나 복제본을 지울 때 `measured.count`를 **그 시점의 도형 수**로 맞춘다(항상). 사용자가 속성창에서 다른 값으로 고치면 그 값이 저장되고, 다음 복제·삭제 때 다시 도형 수로 덮인다. 단순하고 예측 가능한 규칙이다.
- 복제본이 없는 손상(기존 데이터 포함)은 지금과 같다 — 개소를 직접 적는다.
- 치수 문구(`dimensionTextOf`)의 ` nEA`는 지금처럼 `measured.count`를 쓴다.

## 3. 화면

### 3.1 첫 그리기 속성창 자동 열기

- 셀렉트박스(`#damageType`)를 조작하면(`change` 또는 `pointerup`) "다음 새 손상에 속성창 열기" 상태를 켠다. 같은 유형을 다시 골라도 켜진다(`change`가 안 나므로 `pointerup`도 본다).
- 새 손상을 그려 저장하면(`onStroke`/`onRect`) 그 상태가 켜져 있을 때만: 새 손상을 **선택**하고 속성창을 연다. 그리고 상태를 끈다. 켜져 있지 않으면 지금처럼 선택 없이 끝난다.
- 복제·이동·탭 선택은 이 상태와 무관하다.

### 3.2 복제

- 툴바에 **복제** 버튼(선택된 손상이 있을 때만 활성). 누르면 지금 선택된 **도형**(첫 도형이든 복제본이든)을 그 도형의 경계상자 **너비 + 너비의 20%** 만큼 오른쪽으로 옮긴 자리에 복제본으로 더하고, 새 복제본을 선택한다. 사용자는 끌어서 제자리로 옮긴다(이동은 이미 있다).
- 복제본은 `copies`에 붙는다. `dwg`는 world를 `worldToDwg`로 옮겨 만든다(첫 도형과 같은 방식).
- 개소는 2장 규칙대로 도형 수로 맞춘다.
- 되돌리기(마지막 취소)는 문서 편집 단위이므로 복제·복제본 삭제도 한 번에 되돌린다.

### 3.3 선택·이동·삭제 — 도형 단위

- 선택은 (손상 id, 도형 번호 `shapeIndex`)다. 0이 `geometry`, 1부터 `copies[i-1]`. 탭으로 어느 도형을 눌러도 그 손상이 선택되고 `shapeIndex`는 누른 도형이다(`pickDamage`가 도형 번호도 돌려준다).
- 선택 표시: 선택된 손상의 **모든 도형**을 주황으로, 그중 선택된 도형에만 핸들(사각형이면 모서리·회전, 선이면 없음)을 그린다.
- 이동·크기·회전은 **선택된 도형만** 바꾼다(`updateDamage`로 그 도형의 `world`/`dwg`만 갱신). `computed`는 첫 도형을 바꿨을 때만 다시 계산한다.
- "선택 삭제": 선택된 도형만 지운다. 첫 도형을 지우면 `copies[0]`이 새 `geometry`가 된다(번호 라벨이 그 도형으로 옮겨간다). 마지막 남은 도형을 지우면 손상 자체가 사라진다. 지운 뒤 개소를 도형 수로 맞춘다.
- 속성창은 손상 단위다 — 어느 도형을 골라 열어도 같은 속성이다.

### 3.4 그리기·라벨

- `overlay`는 손상의 모든 도형을 같은 스타일(선·해치·기호)로 그린다. 번호 라벨은 **첫 도형** 위에만, 지금 규칙(`labelLayout`/`placeLabels`) 그대로.
- 겹침 방지의 장애물에는 **복제본의 경계상자도** 넣는다(라벨이 복제본 위에 놓이지 않게). 라벨 기준점은 첫 도형 경계상자다.
- 번호·틀 배정은 첫 도형으로 정한다(`computeNumbers`·`frameIndexOf` 변함없음).

## 4. DXF 산출

- 손상마다 첫 도형과 복제본 **모두** 도형·해치·기호를 그린다(`damageEntities`를 도형마다 부른다). 라벨은 첫 도형에 한 번.
- 겹침 장애물에 복제본 경계상자를 넣는다(화면과 같은 입력).
- 물량표: 한 행. 개소 = `measured.count`(자동 또는 사용자 값). 다른 열은 지금과 같다.
- 넘침 장 복사·틀 이동: 도형이 여럿이어도 손상 단위로 같은 이동량(첫 도형이 속한 틀 기준)을 적용한다. 복제본이 다른 틀에 걸쳐 있으면 첫 도형의 틀을 따른다(9장).
- 틀 밖 손상 판정은 첫 도형으로.

## 5. 바뀌지 않는 것

- 문구(`drawingNameOf`·`dimensionTextOf`·`photoTextOf`), 라벨 모양·자리 규칙, 번호 규칙, 틀 인식, 표 채우기, 사진번호 입력.
- 속성창 자체(칸 구성). 개소 칸은 그대로 있고 자동으로 채워질 뿐이다.

## 6. 검증

단위 테스트(순수 함수):

- `damageDoc`: v5 검증(복제본 점 개수·dwg 규칙), v4 → v5 이행(`copies: []`), `duplicateShape(editor, id, shapeIndex, offset)`·`removeShape(editor, id, shapeIndex)`의 결과(copies·geometry 승격·손상 삭제·개소 자동)와 되돌리기.
- `crackTool.pickDamage`: 복제본을 눌러도 손상 id와 도형 번호가 나온다.
- `overlay`: 선택된 손상의 도형 전부 주황, 핸들은 선택 도형만(순수 함수로 뺀 부분만 테스트); `computeLabelPlacements`가 복제본 경계상자를 장애물로 넣는다(복제본 위에 라벨이 안 놓임).
- 산출: 복제본 2개짜리 손상 → 도형 엔티티 3벌, 라벨 1벌, 표 1행(개소 3); 복제본 위로 라벨이 안 감; 넘침 복사에서 복제본도 같이 옮겨짐.
- 화면 글루(속성창 자동 열기·복제 버튼·도형 단위 선택)는 읽기 + `node --check`.

실기기 확인(사용자): 유형 고르고 처음 그리면 속성창이 뜨고 두 번째부터는 안 뜨는지; 복제 → 끌어 옮기기 → 개소가 2, 3으로 바뀌는지; 복제본 하나 삭제 시 그것만 사라지고 개소가 줄어드는지; DXF에 도형 3개·라벨 1개·표 개소 3인지. **서버 재시작 필수.**

## 7. 미해결

- 복제본이 다른 망도틀에 걸치면 첫 도형의 틀을 따른다 — 사내 표기에서 그런 경우가 없다고 본다.
- 복제본에 라벨이 없어 도면에서 어느 손상의 복제본인지는 위치로만 안다(사용자 선택). 필요해지면 복제본에 번호만 작은 원으로 붙이는 것을 검토한다.
- 첫 도형을 지우면 라벨이 다음 도형으로 옮겨간다 — 번호는 첫 도형 위치로 매기므로 번호가 바뀔 수 있다(번호는 저장하지 않으므로 규칙상 당연하다).
