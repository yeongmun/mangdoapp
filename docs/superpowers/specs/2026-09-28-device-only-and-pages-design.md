# 기기 버전으로 통일 + 망도틀 한 페이지씩 보기

- 날짜: 2026-09-28
- 상태: 설계 승인됨(사용자 2026-09-28: "기기에서 내려받는 버전만 있게", "두 가지 버전(전체/한 페이지씩)", "자동으로 받기로 진행").
- 앞선 설계: `2026-09-23-offline-design.md`(오프라인 모드 — 이 설계가 그 위에서 온라인 경로를 없앤다), `2026-09-16-frame-numbering-design.md`(망도틀·번호).

## 1. 기기 버전으로 통일

### 1.1 동작
- 앱에서 도면을 누르면 **항상 기기 파일로 연다.** 기기에 없으면 누르는 순간 자동으로 내려받고(진행 표시) 끝나면 바로 연다. 내려받기 실패 시 목록에 남고 `내려받지 못했습니다: <사유>` 배너.
- 앱의 온라인 뷰어 경로(`viewerUrl`로 서버 페이지 열기)를 없앤다. `ViewerScreen`은 기기 소스만 받는다. (서버의 `viewer.html` 온라인 코드는 지우지 않는다 — PC에서 열 일이 없지만 되돌릴 여지를 남긴다.)
- `viewFormat`이 `svf`가 아닌 옛 도면: 기기로 받을 수 없으므로 누를 수 없고 `PC에서 다시 변환 필요`. 변환 중·실패 도면도 누를 수 없다(지금과 같음).
- 손상·사진은 기기에 먼저 저장, 인터넷이 되면 자동 전송(지금과 같음) + **뷰어를 보고 있는 동안에도** 30초마다와 저장 직후 전송한다(3초 디바운스). 이때 **열어 둔 도면은 push만** 하고 pull은 하지 않는다(뷰어가 들고 있는 문서와 파일이 갈라지지 않게) — `syncOffline({ skipPullFor: drawingId })`.

### 1.2 목록 화면
- 도면 줄 오른쪽 상태 하나: `기기에 있음`(초록) / `받기 필요`(회색) / `PC에서 다시 변환 필요`(회색, 누를 수 없음) / 변환 상태(대기·변환 중·실패 — 지금 배지).
- 줄마다 있던 **내려받기** 버튼을 없앤다.
- 프로젝트 안·미분류의 **이 목록 내려받기**를 **현장 가기 전 모두 받기 (N장)** 로 바꾼다. 0장이면 `모두 기기에 있음`(비활성).
- 위쪽 배지 두 개(사진·손상)를 하나로: `서버에 아직 안 올라감: 손상 N개 · 사진 M장`(0인 쪽은 빼고 쓴다. 예: `서버에 아직 안 올라감: 사진 3장`). 누르면 즉시 전송(사진 재시도 포함). 둘 다 0이면 숨김.
- 내려받는 동안 배너 `내려받는 중 3/7 — <도면 이름>`(지금과 같음). 도면 하나를 눌러 받는 중이면 `여는 중 — <도면 이름>`.
- 길게 누르기 창: `기기에서 지우기`(기기에 있을 때) · `휴지통으로 보내기` · `취소`. 못 올린 손상이 있으면 지금 경고 문구를 붙인다.
- 서버에 없는(휴지통) 기기 도면은 지금처럼 사유 줄과 함께 보인다.

### 1.3 뷰어 화면 헤더
- 오른쪽에 서버 전송 상태: 이 도면의 못 올린 손상(`syncDecision === 'push'`)이나 사진 대기열 항목이 있으면 `연결되면 서버로 전송`(주황), 없으면 `서버 전송 완료`(초록). 저장·전송 뒤마다 갱신.
- `기기 파일` 표시는 없앤다(항상 기기라 의미 없음).

## 2. 망도틀 한 페이지씩 보기

### 2.1 동작
- 뷰어 도구막대에 **전체 | 페이지** 전환(두 버튼, 고른 쪽 강조). 마지막 선택을 앱이 기억한다(`Paths.document/viewer-prefs.json` — `{ viewMode: 'all' | 'page' }`, 기본 `all`). 페이지 모드는 도면 레코드 `frames`가 1개 이상일 때만 켤 수 있고, 없으면 버튼 비활성 + 전체.
- **페이지 모드**: 틀 i의 도면좌표 경계(`frames[i]`, mm)를 `mapper.dwgToWorld`로 네 모서리 변환 → 그 경계상자에 가장자리 여백 3%를 더해 뷰어 카메라를 맞춘다(`viewer.navigation.fitBounds(false, box)`; 2D라 z는 0). 화면 아래 가운데 **◀ 이전 · 3 / 7 · 다음 ▶** (첫/끝에서 해당 버튼 비활성). 순서는 `frames` 배열 순서(서버가 왼쪽→오른쪽으로 정렬해 둔, 틀 번호와 같은 순서).
- 페이지 안에서는 확대·이동·그리기·선택 모두 그대로. 이전/다음을 누르면 그 틀로 다시 맞춘다. 현재 페이지 번호도 도면별로 기억한다(`viewer-prefs.json`의 `pages: { [drawingId]: index }`).
- 쓸어넘기기는 넣지 않는다(그리기와 겹침).
- **전체 모드**: 지금과 같다. 전환할 때 `viewer.fitToView()`.
- 앱 ↔ 뷰어: 앱이 주입하는 `window.mangdoOffline`에 `viewMode`, `pageIndex`를 더한다. 뷰어가 바뀔 때 `postToApp({ type: 'viewPrefs', viewMode, pageIndex })` → 앱이 저장.

### 2.2 순수 규칙 (`server/public/viewer/pageView.js`, vitest)
- `pageCount(frames)`, `clampPage(index, frames)`, `frameWorldBox(frame, dwgToWorld, marginRatio = 0.03)` → `{ minX, minY, maxX, maxY } | null`(변환 불가·빈 틀이면 null), `pageLabel(index, count)` → `'3 / 7'`.

## 3. 바뀌지 않는 것
서버 API, 손상 기록 형식(v5), 사진 대기열, 산출 DXF, 프로젝트·휴지통, 동기화 규칙(`syncDecision`). PC 업로드 페이지.

## 4. 검증
- 단위: `pageView.js` 규칙; `syncOffline`의 `skipPullFor`(순수 부분이 있으면 그것, 없으면 결정 함수 분리); 목록 배지 문구를 만드는 순수 함수 `pendingSummary(damages, photos)`(`src/offlineRules.ts`).
- 실기기(결과 표 74~80행): 기기에 없는 도면을 누르면 자동으로 받아 열림; 옛 도면은 누를 수 없음; 목록 배지 하나로 합쳐짐·누르면 전송; 뷰어에서 그린 손상이 인터넷 되면 뷰어를 닫지 않아도 30초 안에 서버에 감(헤더 `서버 전송 완료`); 페이지 모드 전환·이전/다음·틀에 맞춰짐·그 안에서 그리기; 앱을 껐다 켜도 보기 방식과 페이지 기억; 틀 없는 도면은 페이지 버튼 비활성.
