# 망도 손상조사 태블릿 앱 기능명세서

- 문서 버전: v0.1 (초안)
- 작성일: 2026-09-09
- 대상: 시설물 외관조사(망도) 현장 손상 기록 및 DWG 산출 앱

---

## 1. 개요

### 1.1 목적
현장 조사자가 태블릿에서 캐드 망도(DWG)를 열어 보고, 펜 또는 손가락으로 손상을 직접 표기한 뒤, 손상 내역이 반영된 DWG 파일(손상 도면 + 손상물량표)로 다시 내보내는 앱을 개발한다.

### 1.2 배경 및 전제
- 사내 캐드 환경: 지스타캐드(GstarCAD) 사용. DWG는 표준 포맷이므로 오토캐드 없이 운용 가능
- 현장 인터넷 사용 가능 → 클라우드 기반 구조 채택
- 핵심 기술: Autodesk Platform Services(APS) — Viewer SDK, Model Derivative API, Design Automation API

### 1.3 전체 업무 흐름
1. 사무실: 지스타캐드로 작성한 망도 DWG를 앱(서버)에 업로드
2. 서버: Model Derivative로 뷰어용 포맷 변환
3. 현장: 태블릿에서 망도를 열어 손상 유형 선택 후 펜/손으로 표기
4. 저장: 손상 데이터(좌표·유형·물량)를 JSON으로 서버에 실시간 저장
5. 내보내기: Design Automation이 원본 DWG에 손상 레이어와 손상물량표를 반영한 새 DWG 생성
6. 사무실: 산출된 DWG를 지스타캐드에서 열어 확인·후처리

## 2. 기능 요구사항

### F-1. 도면 업로드 및 변환
| ID | 기능 | 설명 |
|---|---|---|
| F-1.1 | DWG 업로드 | 사용자가 DWG 파일을 앱/웹에서 업로드. 프로젝트·시설물 단위로 분류 저장 |
| F-1.2 | 뷰어용 변환 | 업로드 시 Model Derivative API로 뷰어 포맷(SVF/SVF2) 자동 변환. 변환은 도면당 1회 |
| F-1.3 | 변환 상태 표시 | 변환 진행 중/완료/실패 상태를 목록에 표시. 실패 시 원인 안내 및 재시도 |
| F-1.4 | 도면 목록 관리 | 프로젝트별 도면 목록 조회, 검색, 삭제, 버전 관리 |

### F-2. 도면 뷰어
| ID | 기능 | 설명 |
|---|---|---|
| F-2.1 | 도면 표시 | APS Viewer SDK 기반으로 태블릿(브라우저/웹뷰)에서 망도 표시 |
| F-2.2 | 화면 조작 | 핀치 줌, 팬(이동), 초기화면 복귀. 확대/축소 시에도 손상 표기는 도면 좌표에 고정 |
| F-2.3 | 레이어 제어 | 원본 도면 레이어 및 손상 레이어 표시/숨김 |
| F-2.4 | 축척 인식 | 도면 좌표계 기준으로 실제 길이·면적 계산이 가능하도록 축척 정보 관리 |

### F-3. 손상 입력 (핵심 기능)
| ID | 기능 | 설명 |
|---|---|---|
| F-3.1 | 손상 유형 선택 | 균열, 박리, 박락, 백태, 철근노출, 누수 등 손상 유형 팔레트 제공. 유형별 색상·심볼·선종류 정의 |
| F-3.2 | 유형별 입력 방식 | 선형 손상(균열 등): 폴리라인 / 면형 손상(박리 등): 폐합 영역 / 점형 손상: 심볼 배치. 자유곡선 난개발 방지를 위해 유형별 입력 방식 고정 |
| F-3.3 | 펜·터치 입력 | 스타일러스(애플펜슬, S펜) 및 손가락 입력 지원. 팜 리젝션 적용 |
| F-3.4 | 물량 자동 계산 | 도면 좌표 기반으로 균열 길이(m), 손상 면적(㎡) 자동 산출. 균열 폭 등 수치 속성은 직접 입력 |
| F-3.5 | 손상 속성 입력 | 손상별 부재명, 위치, 폭/깊이, 사진 첨부, 비고 입력 |
| F-3.6 | 수정·삭제 | 입력한 손상 선택 후 이동, 수정, 삭제. 실행취소(Undo)/재실행(Redo) |
| F-3.7 | 자동 저장 | 손상 데이터는 JSON 형식으로 서버에 실시간(또는 주기적) 자동 저장 |

### F-4. 손상물량표
| ID | 기능 | 설명 |
|---|---|---|
| F-4.1 | 물량 집계 | 손상 유형별·부재별 개소 수, 총 길이, 총 면적 자동 집계 |
| F-4.2 | 앱 내 물량표 조회 | 조사 중 실시간으로 물량표 확인 가능 |
| F-4.3 | DWG 물량표 반영 | 내보내기 시 물량표를 DWG의 Table 객체로 생성/갱신. 원본 물량표가 Table 객체면 셀 값 갱신, 선+문자 표이면 새 Table 객체 생성 방식으로 우회 |

### F-5. DWG 내보내기
| ID | 기능 | 설명 |
|---|---|---|
| F-5.1 | DWG 생성 | Design Automation(AutoCAD 엔진)으로 원본 DWG에 손상 엔티티를 손상 레이어로 삽입하고 물량표를 반영한 새 DWG 생성 |
| F-5.2 | 레이어 규칙 | 손상 유형별 레이어명·색상·선종류를 사내 도면 표준에 맞게 매핑 |
| F-5.3 | 다운로드 | 생성된 DWG를 다운로드 또는 지정 저장소로 전송 |
| F-5.4 | 왕복 호환성 | 산출 DWG가 지스타캐드에서 정상적으로 열리고 Table 서식이 유지되는지 보장 (초기 왕복 테스트 필수) |

### F-6. 사용자·프로젝트 관리
| ID | 기능 | 설명 |
|---|---|---|
| F-6.1 | 로그인/권한 | 조사자, 관리자 권한 구분 |
| F-6.2 | 프로젝트 관리 | 시설물·교량·구간 단위 프로젝트 생성 및 도면 매핑 |
| F-6.3 | 조사 이력 | 손상 입력자, 입력 일시 기록. 조사 회차별 데이터 구분 |

|---|---|

## 4. 기술 구성

| 구성요소 | 기술 | 비고 |
|---|---|---|
| 도면 뷰어 | APS Viewer SDK | 무료 API. MarkupsCore 확장 기반 커스텀 손상 도구 개발 |
| 도면 변환 | APS Model Derivative | DWG는 단순 작업으로 건당 0.1토큰(약 400원 수준) |
| DWG 생성/수정 | APS Design Automation (AutoCAD 엔진) | 처리 시간당 2토큰. 도면 1건 처리 시 건당 100~200원 수준 예상 |
| 인증/파일 관리 | APS Authentication, Data Management | 무료 API |
| 손상 데이터 | 자체 서버 + JSON | 좌표·유형·물량·속성 저장 |
| 사내 캐드 | 지스타캐드 | DWG 표준 호환. Table 객체 왕복 테스트 필요 |

### 4.1 예상 운영 비용 (참고)
- Flex 토큰 단가 약 $3/토큰, 12개월 내 사용
- 예시: 월 도면 100장 변환 + DWG 내보내기 200회 → 월 5~8만 원 수준
- 오토데스크 요금제 개편(Free/Paid 2단계, 월 무료 사용량 제공 및 일부 단가 인상) 진행 중이므로 개발 착수 시점에 APS 콘솔에서 최신 단가 재확인

## 5. 개발 단계 제안

| 단계 | 내용 | 검증 목표 |
|---|---|---|
| 1단계 (PoC) | DWG 업로드 → 뷰어 표시 → 펜으로 손상 1종 입력 → JSON 저장 | 뷰어 위 좌표 기반 입력 검증 |
| 2단계 | Design Automation으로 손상 레이어 삽입된 DWG 산출 → 지스타캐드 왕복 테스트 | DWG 왕복 호환성, Table 객체 서식 유지 검증 |
| 3단계 | 손상 유형 전체 구현, 물량 자동 계산, 물량표 자동 작성 | 물량 집계 정확도 검증 |
| 4단계 | 프로젝트/사용자 관리, 조사 이력, 사진 첨부 등 운영 기능 | 실 현장 파일럿 적용 |

## 6. 확인 필요 사항 (Open Issues)

1. 기존 망도의 손상물량표가 Table 객체인지, 선+문자 조합인지 표본 확인
2. 손상 유형 목록과 유형별 물량 산정 기준(사내 표준) 확정
3. 손상 레이어 명명 규칙 등 도면 표준 확정
4. 지스타캐드 버전별 Table 객체 호환성 왕복 테스트
5. 조사 사진 첨부 시 DWG 반영 여부(도면 내 삽입 vs 별도 보고서)
6. 오프라인 임시 저장 범위(터널·교량 하부 등 통신 음영 구간 대응 수준)
